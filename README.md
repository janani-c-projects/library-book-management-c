# Library Book Management System

## 1. Project Overview
The Library Book Management System is a menu-driven application developed using the C programming language. It helps manage book records and their availability.

## 2. Objective
To develop a simple application that allows users to add, display, search, issue and return library books.

## 3. Features
- Add book records
- Display all stored books
- Search for books using Book ID
- Issue available books
- Return issued books
- Prevent duplicate Book IDs
- Display book availability status

## 4. Programming Concepts Used
- Structures
- Arrays
- Functions
- Loops
- Switch-case statements
- If-else statements
- Searching
- Input and output functions

## 5. How to Run
1. Download the `main.c` file.
2. Open it in a C compiler.
3. Compile and run the program.
4. Select an option from the menu.

## 6. Programming Language
C
